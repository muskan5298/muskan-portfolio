MUSKAN — BANKING + AI PORTFOLIO

Files:
- index.html: one-page portfolio designed as seven full-screen slides
- student-illustration.png: original cute student illustration used in the hero section

To preview:
Open index.html in a browser. Keep student-illustration.png in the same folder.

To publish with GitHub Pages:
1. Create a public repository named muskan-portfolio.
2. Upload BOTH index.html and student-illustration.png to the repository root.
3. Go to Settings > Pages.
4. Under Build and deployment, select Deploy from a branch, branch main, folder /(root), then Save.
5. Wait for GitHub Pages to provide the public site URL.

Before publishing:
- Replace ADD-YOUR-EMAIL with your email, or remove the email button.
- Add exact IBM course names and certificate links.
- Confirm the project descriptions match what you built.
